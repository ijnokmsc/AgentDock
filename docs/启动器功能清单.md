## 2. 核心层 API 索引（src/core|app|platform|storage，纯 C++ 零 Qt，v3 直接链接）

### hs::Paths（src/app/Paths.h，全静态）
`setRoot(fs::path)->bool`（指纹校验）/ `autoDetect()->bool` / `root()` / `portableRoot()` / `isValid()` / `isOfficialLayout()` / `resolveRootFromSettings()`；目录：`dataDir/studioDir/pluginDir/logsDir/backupDir/downloadDir/envFile/configFile`；运行时：`venvPython/nodeExe/webUiEntry`；`sandboxVarTable()/createSandboxDirs()`

### hs::Types（src/core/Types.h）
`Result<T>/Error`；`ProviderKind/StartMode{Cli,WebUI,Desktop}/CheckLevel/HermesState{Stopped,Starting,Running,Stopping,Failed}/ComponentId{Kernel,WebUI,PythonRuntime,NodeRuntime,Launcher}`；
`Provider{id,displayName,kind,baseUrl,envVar,apiKey,enabled}`；`Model{id,providerId,upstreamId,displayName,params,isDefault}`；`RuntimeConfig{hermesRoot,webUiPort=8648,startMode,autoCheckUpdate,launchOnStart,updateChannel,backupKeepCount}`；`NetSettings{mode(ProxyMode System/Direct/Manual),host,port,githubMirror,...}`；`AppSettings{schemaVersion,runtime,network,locale}`；`CheckItem{id,title,level,detail,fixable,fixAction}`；`ComponentState{id,name,currentVersion,latestVersion,installPath,updateAvailable,supported,note}`

### hs::Launcher（src/core/Launcher.h）
`start(StartMode, port=8648)->StartResult{ok,message,pids}` / `stop()->bool` / `state()->HermesState` / `modeAvailable(StartMode)->bool` / `modeUnavailableReason()` / `webUiUrl(port)`

### hs::Updater（src/core/Updater.h）★
`scanLocal()->vector<ComponentState>`（慢，执行 --version）/ `scanWithRemote(channel)` / `checkRemote(id,channel)->RemoteResult` / `applyKernelUpdate(ver,progress)` / `applyWebUiUpdate(ver,progress)` / `applyNodeUpdate(ver,progress)` / `listNodeVersions(30)->vector<string>` / `compareVersion(a,b)`

### hs::UpdateManager（src/core/UpdateManager.h）★备份回滚
`backupComponent(src,name,tag,err)` / `rollback(backupPath,err)->bool` / `atomicReplace(src,dest,name,ver,progress)` / `listBackups(name)->vector<fs::path>`；备份根 `studio/backups/<name>/<tag>/`

### hs::PortableBuilder（src/core/PortableBuilder.h）★
`BuildOptions{targetDir(空=portableRoot),platform="win-x64",useCache,verifySha256,githubMirror}`；`BuildProgress{percent,stage}`；`BuildResult{ok,cancelled,message,targetDir,runtimeVersion,webUiVersion}`；`resolveLatest(platform,mirror)->RemoteInfo{runtime/webUi 的 tag/version/url/sha256/size}`；`run(opts,ProgressFn,CancelFn)->BuildResult`（下载→sha256→解包→组装→写bat→修pyvenv→验证 import hermes_cli）；`fixPyvenvHome(root,err)`

### hs::PreflightChecker（src/core/PreflightChecker.h）
`Context{modelConfig,runtime,haveModels,hermesRunning}`；`runAll()->vector<CheckItem>`；`applyFix(action)->string`；`canLaunch()->bool`；fixAction 约定 `auto:<id>`/`goto:<page>`

### hs::ModelRegistry（src/core/ModelRegistry.h）
构造 `ModelRegistry(fs::path models.json)`；`load()/save()`；Provider：`providers()/provider(id)/addProvider/updateProvider/removeProvider(连带删模型)`；Model：`models()/modelsOf(pid)/addModel/updateModel/removeModel/setDefault`；`migrateFromLegacy(envFile,configFile,templateOut)->MigrationResult`；`validate()`

### hs::PluginHost（src/core/PluginHost.h，完整版）
目录 `<root>/plugin/<id>/{plugin.dll,plugin.json}`；状态 `data/studio/plugins-state.json`；
`discover()/loadAll()/reload()`；`allPlugins()/loadedPlugins()`；`setEnabled(id,bool,err)/removePlugin(id,err)`；
`uiEntriesOf(id)->const vector<UiEntry>*`（UiEntry{id,title,icon,jsonSchema,defaultConfig,actions}）；`executeAction(pid,aid,payload)->hs_i32`；`dispatch(hs_event,payload)->bool`（false=veto）

### hs::ConfigRenderer / hs::JsonStore
`ConfigRenderer(envOut,yamlOut,template)`：`renderAll(cfg,rt,opt)/restore()/externallyModified()`；
`JsonStore::load(path)->optional<json>` / `save(path,json)`（原子替换+.bak）/ `appendLine` / `ensureParent`

### 链接要求
bcrypt(Hash) / winhttp(HttpClient) / ws2_32+iphlpapi(PortScanner) / version(预留) / miniz 四个 .c 按 C 编译(Archive)

## 3. settings.json schema（studio/settings.json，实测）
```json
{ "schemaVersion": 1, "locale": "zh-CN",
  "network": { "mode": 0, "host": "", "port": 0, "githubMirror": "", ... },
  "runtime": { "hermesRoot": ".", "webUiPort": 8648, "startMode": 1,
               "autoCheckUpdate": true, "launchOnStart": false,
               "updateChannel": "stable", "backupKeepCount": 3 } }
```
`network.mode`: 0=System/1=Direct/2=Manual；`startMode`: 0=Cli/1=WebUI/2=Desktop
